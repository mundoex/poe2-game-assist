# Poe2 Game Assist

Screen-reading overlay/automation tool for Path of Exile 2. It samples pixel colors from the health, mana, energy shield, and rage globes to detect threshold events (e.g. low health, low mana, poisoned) and triggers configured actions (potions, abilities) in response.

## Known limitations

- The combination of **Poison | Chaos Inoculation | Health with Runic Ward** is untested but might work
- Not working for linux needs more work but was designed with it in mind
